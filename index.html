Setup

From download to first license

Windows desktop

  1. Download and run the signed Windows installer.
  2. Launch License Center from the Start menu.
  3. Complete initial setup and request an activation from ImpleoTV.

The installer can install Microsoft Edge WebView2 Runtime for you.

Debian / Ubuntu

Requires Docker Engine, Docker Compose v2, and systemd. Supports AMD64 and ARM64.

  1. Download the Debian deployment package.
  2. Install and configure it:
    sudo apt install ./license-center_VERSION_all.deb
sudo license-centerctl configure
  3. Enter your public HTTPS URL and reverse-proxy port, then open that URL to complete setup.

The package pulls the public, versioned container image automatically. The default proxy port is 6000 on localhost.

Standalone servers

  1. Choose the binary matching your operating system and architecture. On Linux, make the downloaded file executable.
  2. Set LICENSE_CENTER_MASTER_KEY to a securely generated 32-byte base64 key and set LICENSE_CENTER_PUBLIC_URL to your HTTPS address.
  3. Start the binary with persistent storage and configure an HTTPS reverse proxy. The default listener is 127.0.0.1:8080.

Back up your data directory and master key together. Use the application’s built-in manual for configuration details.

Verify your download

Download SHA256SUMS.txt from the same release and compare the hash for your file.

Windows PowerShell:

Get-FileHash .\license-center-amd64-installer.exe -Algorithm SHA256

Linux, from the directory containing your downloads:

sha256sum --check --ignore-missing SHA256SUMS.txt
